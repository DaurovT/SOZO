# Вторая тридцатка: B2B, B2C и админка (31–60)

Найдено вторым обходом кода. Здесь другой класс разрывов: не «данные не дошли»,
а «условие объявлено и не исполняется». Договор обещает штрафы, перенос остатка,
SLA по авариям, заморозку цен — в коде этих слов нет нигде, кроме экрана, который
их показывает. Паспорт объекта заполняется и не участвует ни в одном расчёте.

## Уже закрыто по дороге

- Наценка «Срочно» снималась только флагом — сумма оставалась с +30%. Планировщик
  теперь пересчитывает итог (проверено: 91 000 → 70 000).

  эндпоинтов не было.

- Код приёмки у мастера не сверялся ни с чем: проходили любые четыре цифры.

*Проверка на чистой базе:*
- `node apps/api/test/client-app-e2e.mjs` — 90 сквозных по клиентскому контуру
- `node apps/api/test/b2b-e2e.mjs` — 49 сквозных по B2B: организация → точка →
  ответственные → заявка → утверждение → приёмка → счёт
- `node apps/api/test/web-card-e2e.mjs` — 29 сквозных по веб-карточке:
  ссылка → статус → смета → акт → оплата → оценка, плюс отзыв ссылки
- `flutter test` в `apps/client-app` — 61 (56 экранных + 5 словарных),
  в `apps/master-app` — 52

*Что нашли сами прогоны, а не обход кода:*
- «Без потолка» в админке превращалось в ноль — руководитель организации
  заводился с нулевым лимитом и не мог утвердить вообще ничего;
- «Применить пороги договора» понижало руководителя организации до сотрудника,
  потому что роль выводится из отсутствия потолка;
- приёмку ответственного конвейер не видел: `acceptanceFixed` приходил флагом
  от диспетчера, а не читался с заявки — работу можно было закрыть без клиента.
