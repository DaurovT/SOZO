## Языки

Десять языков: `ru`, `uz`, `en`, `tr`, `tg`, `ar`, `fr`, `de`, `zh`, `ko`.
Ключи — как в DEV-08: `экран.элемент`. Пропущенный ключ показывает русскую
строку, а не пустоту: незнакомое слово человек хотя бы узнает по виду,
`c14.quickTitle` — нет.

### Два сорта языков

| | Где лежит | Когда доступен |
|---|---|---|
| `ru`, `uz`, `en` | `lib/i18n/dict_*.dart`, внутри сборки | всегда, в том числе без сети |
| остальные семь | `apps/api/src/i18n/client-*.ts`, на сервере | после первой загрузки, дальше из кеша |

Русский, узбекский и английский — языки Ташкента: на них приходит
подавляющее большинство, и первый экран обязан открыться без сети.
Остальные семь весят вместе 328 КБ против 140 КБ встроенных — держать их в
каждой установке ради единиц значит утяжелять сборку всем остальным.

Отсюда вся асинхронность в `L10n`: `set()` для встроенного языка срабатывает
мгновенно, для догружаемого возвращает `Future<bool>` и по дороге сообщает о
ходе через `status`, чтобы лист выбора показал крутилку, а не замер молча.
`false` означает «язык не сменился» — лист остаётся открытым и показывает
причину, а не откатывается к прежнему языку без объяснений.

Кеш живёт в `SharedPreferences` вместе с отпечатком `rev`. При запуске
догружаемый язык поднимается из кеша, а не из сети: запуск не должен
зависеть от связи. Если кеша нет — приложение переустановили или почистили
данные — честно откатываемся на русский. Сверка отпечатка идёт в фоне после
`runApp` (`refreshInBackground`): перевод правят раз в месяц, а приложение
открывают каждый день.

Эндпоинты (без авторизации — язык выбирают до входа):

```
GET /v1/public/app-locale        список языков с отпечатками
GET /v1/public/app-locale/:code  словарь: { code, rev, strings }
```

### Письмо справа налево

Арабский разворачивает раскладку через `Directionality` в `main.dart`, а не
через `flutter_localizations`: делегаты тянут перевод системных виджетов,
которых в экранах нет (DEV-12 правило 3 запрещает Material-иконки и
Material-диалоги), а переворачивать дерево всё равно нужно целиком. Список
`L10n.rtlCodes` честнее булева поля — фарси и иврит добавляются туда, а не
правкой условия по всему коду.

### Серверные строки

Половина того, что видит человек, приходит с сервера: причины отказа,
вопросы экзамена, тексты ошибок, уведомления. Они переведены отдельно —
`apps/api/src/common/locale-*.ts`, ключ там сама русская строка. Приложение
сообщает язык заголовком `Accept-Language`.

### Проверка

```bash
node tools/check-dicts.mjs         # из корня sozo/ — все ли ключи на месте
node tools/check-translations.mjs  # а что в них написано
```

Первая сверяет наборы ключей всех десяти словарей — и встроенных, и
серверных. Ловит пропущенный ключ, лишний, потерянный плейсхолдер `{p1}`,
пустое значение и неэкранированный `$` (в Dart это интерполяция, а не знак
доллара).

Вторая смотрит на содержимое: строку, оставшуюся русской, символ `�` от
потерянной кодировки, плейсхолдер, прилипший к слову. Прилипшие пробелы
чинятся скриптом `tools/fix-holder-spacing.mjs`.

Добавление языка: перевод кладётся в `apps/api/src/i18n/client-<код>.ts`,
код дописывается в `L10n.codes`, `names`, `shortNames` и в `DICTS` на
сервере. Скрипт `tools/build-client-locales.mjs` переносит готовый
`dict_<код>.dart` на сервер, если язык переводили внутри приложения.
