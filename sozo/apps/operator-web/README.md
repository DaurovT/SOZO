# operator-web — кабинет эксплуатирующей организации

React SPA для управляющих компаний, служб эксплуатации бизнес-центров, техотделов сетей и FM-подрядчиков.
Спецификация экранов — **PRD-07**, контур — **DEV-15**, токены — **DEV-06**.

```bash
npm install
npm run dev   # http://localhost:5176/operator/
```

Требует запущенный API: `npm run api` в корне монорепозитория.

## Почему это отдельное приложение

Сажать оператора в диспетчерскую нельзя — там заявки всех клиентов; в админку тем более — она принадлежит
владельцу платформы. Кабинет обслуживает **внешних по отношению к платформе людей** со своей моделью прав
и мультиобъектностью (DEV-07 §1).
